Jag's directory

A tiny macOS Finder utility for copying local file links into AI prompts, notes, and tasks.

When an AI needs to read a local file, the first friction is often just telling it where the file is. Jag's directory adds simple Finder actions for copying and reopening exact local paths.

Install

Clone the repository and run the installer. It creates Automator Quick Actions in ~/Library/Services.

git clone https://github.com/jagyamamoto/jags-directory.git
cd jags-directory
./install.sh

AI Install Prompt

Clone https://github.com/jagyamamoto/jags-directory.git into a normal local projects folder, not Dropbox/iCloud/Google Drive/OneDrive.
